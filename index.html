Privacy Policy

Questa Privacy Policy descrive come l'app Registro del Capitano gestisce i dati degli utenti.

Registro del Capitano è un'app non ufficiale pensata per aiutare i giocatori a gestire punteggi, giocatori, storico partite e backup relativi al gioco da tavolo Skull King.

Titolare e contatto

Sviluppatore: Guglielmo Giambelli

Contatto privacy: guglielmo.giambelli@gmail.com

Dati gestiti dall'app

L'app può gestire i seguenti dati inseriti volontariamente dall'utente:

  • nomi dei giocatori;
  • avatar o immagini dei giocatori, se l'utente decide di aggiungerli;
  • dati delle partite, come punteggi, puntate, prese, bonus, durata dei round e storico;
  • gruppi di giocatori salvati dall'utente;
  • file backup JSON esportati o importati dall'utente.

L'app non richiede la creazione di un account.

Dove vengono salvati i dati

I dati vengono salvati localmente sul dispositivo dell'utente.

Registro del Capitano non invia i dati dei giocatori, le immagini, lo storico o i backup a server proprietari dello sviluppatore.

Fotocamera e immagini

L'app può richiedere accesso a fotocamera o immagini del dispositivo solo per permettere all'utente di aggiungere o modificare l'avatar di un giocatore.

Le immagini selezionate o scattate vengono usate solo all'interno dell'app come avatar dei giocatori e vengono salvate localmente sul dispositivo.

Backup e importazione dati

L'app permette all'utente di esportare un file backup in formato JSON.

Il file backup può contenere nomi dei giocatori, avatar, storico partite, partita in corso e altri dati necessari al ripristino dell'app.

L'utente è responsabile della conservazione e della condivisione del file backup. Chiunque abbia accesso al file backup potrebbe leggere o importare i dati contenuti.

Donazioni tramite PayPal

L'app contiene un link esterno a PayPal per eventuali donazioni volontarie.

Quando l'utente preme il pulsante di donazione, viene aperto PayPal tramite browser o app esterna. Registro del Capitano non gestisce direttamente pagamenti, dati finanziari o credenziali PayPal.

L'uso di PayPal è soggetto alle condizioni e alla privacy policy di PayPal.

Condivisione dei dati

Registro del Capitano non vende i dati degli utenti.

Registro del Capitano non condivide dati personali con server proprietari dello sviluppatore.

Eventuali condivisioni avvengono solo su azione dell'utente, ad esempio quando esporta un backup o apre un servizio esterno come PayPal.

Conservazione e cancellazione dei dati

I dati restano salvati sul dispositivo finché l'utente non li cancella.

L'utente può cancellare i dati:

  • usando la funzione "Cancella tutti i dati" presente nell'app;
  • cancellando i dati dell'app dalle impostazioni del dispositivo;
  • disinstallando l'app.

L'app non dispone di account online e quindi non conserva dati su server associati a un profilo utente.

Sicurezza

I dati vengono salvati localmente sul dispositivo.

L'app non trasmette i dati di gioco a server proprietari. I file backup esportati devono essere custoditi con attenzione dall'utente, perché possono contenere informazioni e immagini inserite nell'app.

Minori

Registro del Capitano non è progettata per raccogliere intenzionalmente dati personali di minori.

L'app è pensata come strumento di supporto per il conteggio dei punti durante una partita da tavolo.

Modifiche a questa Privacy Policy

Questa Privacy Policy può essere aggiornata in futuro per riflettere modifiche all'app o requisiti normativi.

La versione aggiornata sarà resa disponibile tramite il canale scelto per la distribuzione dell'app.

Disclaimer

Registro del Capitano è un'app non ufficiale e non è affiliata, approvata o sponsorizzata dai proprietari del gioco da tavolo Skull King.

Privacy Policy

This Privacy Policy explains how the Registro del Capitano app handles user data.

Registro del Capitano is an unofficial companion app designed to help players manage scores, players, match history and backups for the Skull King board game.

Owner and contact

Developer: Guglielmo Giambelli

Privacy contact: guglielmo.giambelli@gmail.com

Data handled by the app

The app may handle the following data voluntarily entered by the user:

  • player names;
  • player avatars or images, if the user chooses to add them;
  • match data, such as scores, bids, tricks, bonuses, round duration and match history;
  • player groups saved by the user;
  • JSON backup files exported or imported by the user.

The app does not require account creation.

Where data is stored

Data is stored locally on the user's device.

Registro del Capitano does not send player data, images, history or backups to servers owned by the developer.

Camera and images

The app may request access to the device camera or images only to allow the user to add or edit a player's avatar.

Selected or captured images are used only inside the app as player avatars and are stored locally on the device.

Backup and data import

The app allows the user to export a backup file in JSON format.

The backup file may contain player names, avatars, match history, the active match and other data required to restore the app.

The user is responsible for storing and sharing the backup file. Anyone with access to the backup file may be able to read or import the data it contains.

Donations through PayPal

The app contains an external PayPal link for optional voluntary donations.

When the user taps the donation button, PayPal is opened through a browser or an external app. Registro del Capitano does not directly handle payments, financial data or PayPal credentials.

Use of PayPal is subject to PayPal's own terms and privacy policy.

Data sharing

Registro del Capitano does not sell user data.

Registro del Capitano does not share personal data with servers owned by the developer.

Any sharing only happens as a result of a user action, for example when exporting a backup or opening an external service such as PayPal.

Data retention and deletion

Data remains stored on the device until the user deletes it.

The user can delete data by:

  • using the "Delete all data" feature inside the app;
  • clearing the app data from the device settings;
  • uninstalling the app.

The app does not provide online accounts and therefore does not store data on servers associated with a user profile.

Security

Data is stored locally on the device.

The app does not transmit game data to servers owned by the developer. Exported backup files should be kept carefully by the user, as they may contain information and images entered in the app.

Children

Registro del Capitano is not designed to intentionally collect personal data from children.

The app is intended as a support tool for score keeping during a board game session.

Changes to this Privacy Policy

This Privacy Policy may be updated in the future to reflect changes to the app or legal requirements.

The updated version will be made available through the chosen distribution channel for the app.

Disclaimer

Registro del Capitano is an unofficial app and is not affiliated with, endorsed by, or sponsored by the owners of the Skull King board game.

This page is provided to inform users about how the Registro del Capitano app handles data.
